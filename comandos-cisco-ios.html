🏷️ Nomenclatura de Roteadores e Interfaces

🔤 Nomenclatura de Interfaces Cisco

Formato: [TIPO][SLOT]/[PORTA] ou [TIPO][NÚMERO]

📡 Tipos de Interfaces Comuns:

FastEthernet (Fa)

100 Mbps
Exemplo: FastEthernet0/0
Abreviação: Fa0/0

GigabitEthernet (Gi)

1000 Mbps (1 Gbps)
Exemplo: GigabitEthernet0/0
Abreviação: Gi0/0

Serial (Se)

Conexões WAN
Exemplo: Serial0/0/0
Abreviação: Se0/0/0

Ethernet (Et)

10 Mbps (legado)
Exemplo: Ethernet0
Abreviação: Et0

VLAN

Interface lógica
Exemplo: Vlan1
Para roteamento entre VLANs

Loopback

Interface virtual
Exemplo: Loopback0
Sempre ativa (não cai)

📝 Exemplos de Nomenclatura:

# Roteadores modulares (com slots)
GigabitEthernet0/0/0 → Slot 0, Módulo 0, Porta 0
Serial0/1/0 → Slot 0, Módulo 1, Porta 0

# Roteadores fixos (sem slots)
FastEthernet0/0 → Porta 0
GigabitEthernet0/1 → Porta 1

# Switches
FastEthernet0/1 → Porta 1
GigabitEthernet1/0/1 → Stack 1, Módulo 0, Porta 1

🚪 Modos de Operação e Navegação

1️⃣ Modo EXEC Usuário (User EXEC Mode)

Router> # Prompt com >
# Comandos limitados - apenas visualização básica
enable → Entra no modo privilegiado
show version → Mostra informações básicas do sistema

2️⃣ Modo EXEC Privilegiado (Privileged EXEC Mode)

Router# # Prompt com #
# Acesso a todos os comandos show e debug
configure terminal → Entra no modo de configuração global
disable → Volta para modo usuário
exit → Sai do roteador

3️⃣ Modo de Configuração Global (Global Configuration Mode)

Router(config)# # Prompt com (config)#
# Configurações que afetam todo o dispositivo
interface [tipo][número] → Entra em modo de configuração de interface
hostname [nome] → Define o nome do roteador
exit → Volta para modo privilegiado

4️⃣ Modo de Configuração de Interface (Interface Configuration Mode)

Router(config-if)# # Prompt com (config-if)#
# Configurações específicas de uma interface
ip address [IP] [máscara] → Define IP da interface
no shutdown → Ativa a interface
exit → Volta para modo de configuração global

⚡ Atalhos Importantes:

Tab → Completa comandos automaticamente
Ctrl+Z → Volta para modo privilegiado de qualquer modo
? → Mostra ajuda de comandos disponíveis
comando ? → Mostra parâmetros do comando

⚙️ Comandos de Configuração Essenciais

🏷️ Configuração Básica do Dispositivo

Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# enable secret cisco123 # Senha criptografada
R1(config)# banner motd # Acesso Restrito! #
R1(config)# no ip domain-lookup # Desativa DNS

🔌 Configuração de Interface

R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# description LAN Setor A
R1(config-if)# no shutdown # Ativa interface
R1(config-if)# exit

# Para interface serial (WAN)
R1(config)# interface Serial0/0/0
R1(config-if)# ip address 10.0.0.1 255.255.255.252
R1(config-if)# clock rate 64000 # Apenas no lado DCE
R1(config-if)# no shutdown

🛣️ Roteamento Estático

R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2
R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2 # Rota padrão

💾 Salvar Configuração

R1# copy running-config startup-config
# Ou use o atalho:
R1# write # Mesmo efeito
R1# wr # Atalho ainda mais curto

⚠️ Importante!

Sempre salve suas configurações com copy run start
Se não salvar, as configurações são perdidas ao reiniciar
Use no antes do comando para desfazer configurações

🔍 Comandos de Verificação (Show Commands)

📊 Informações do Sistema

show version
Versão IOS, modelo, memória, uptime
show running-config
Configuração ativa (na RAM)
show startup-config
Configuração salva (na NVRAM)
show flash
Arquivos na memória flash

🔌 Interfaces

show ip interface brief
Resumo de todas as interfaces
show interfaces
Detalhes de todas as interfaces
show interface Gi0/0
Detalhes de uma interface específica

🛣️ Roteamento

show ip route
Tabela de roteamento completa
show ip route static
Apenas rotas estáticas
show ip protocols
Protocolos de roteamento ativos

🔍 Diagnóstico

ping [IP]
Testa conectividade
traceroute [IP]
Mostra caminho dos pacotes
show arp
Tabela ARP (IP → MAC)
show mac address-table
Tabela MAC (apenas switches)

💡 Exemplo Prático:

R1# show ip interface brief
Interface IP-Address Status Protocol
GigabitEthernet0/0 192.168.1.1 up up
GigabitEthernet0/1 unassigned down down
Serial0/0/0 10.0.0.1 up up

# Status = camada física | Protocol = camada de enlace
# up/up = funcionando corretamente
# administratively down = interface desligada com shutdown

📋 Resumo e Comandos Rápidos

🚀 Fluxo Básico de Configuração

# 1. Entrar no modo de configuração
Router> enable
Router# configure terminal

# 2. Configurar hostname e senha
Router(config)# hostname R1
R1(config)# enable secret minhasenha

# 3. Configurar interface
R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit

# 4. Adicionar rota estática
R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2

# 5. Salvar configuração
R1(config)# exit
R1# copy running-config startup-config

⚡ Comandos Mais Usados

enable - Modo privilegiado
conf t - Modo configuração
int Gi0/0 - Entra na interface
no shut - Ativa interface
show ip int brief - Lista interfaces
show ip route - Tabela roteamento
wr - Salva configuração

🛠️ Comandos de Recuperação

reload - Reinicia o dispositivo
erase startup-config - Apaga config salva
no [comando] - Remove configuração
show running-config - Ver config atual

⚠️ Lembretes Importantes

Sempre use ? para ver ajuda disponível
Use Tab para completar comandos
Salve com wr ou copy run start
Ctrl+Z volta para modo privilegiado
no shutdown ativa interfaces (não esqueça!)
