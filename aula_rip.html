🌐 RIP

Routing Information Protocol

Roteamento Dinâmico com Vetor de Distância

📚 Curso

Técnico Integrado em Informática
Arquitetura de Redes de Computadores
Tecnologias de Implementação de Redes
Modelo TCP/IP - Camada de Rede

💡 Dica: Use as setas ⬅️ ➡️ do teclado para navegar

📡 O que é RIP?

RIP = Routing Information Protocol
É um protocolo de roteamento dinâmico baseado em vetor de distância
Permite que roteadores troquem informações automaticamente
Ideal para redes pequenas e médias

🎯 Características Principais

Métrica: Contagem de saltos (hops)
Limite máximo: 15 saltos
Rotas com mais de 15 saltos são consideradas inalcançáveis
Roteador A → Roteador B → Roteador C
(1 salto) → (2 saltos) → (3 saltos)

💡 Menor número de saltos = Melhor rota

⚙️ Como o RIP Funciona?

🔄 Atualizações Periódicas

O RIP envia a tabela de roteamento completa a cada 30 segundos
Envia para todas as interfaces ativas do roteador
Permite que os vizinhos atualizem suas tabelas de roteamento

⚠️ Ponto de Atenção

Enviar a tabela completa a cada 30s pode gerar tráfego desnecessário
Em redes muito grandes, isso pode sobrecarregar os links

📊 Exemplo Prático

Imagine que você tem uma agenda telefônica. A cada 30 segundos, você liga para todos os seus amigos e diz: "Olha, eu conheço fulano no número X, sicrano no número Y, etc.". É assim que o RIP funciona! Ele "fofoca" todas as rotas que conhece para seus vizinhos regularmente.

🔢 Versões do RIP

📌 RIPv1 (Versão 1)

Classful: NÃO suporta VLSM/CIDR
Broadcast: Envia atualizações por broadcast
Sem máscara: Não inclui máscara de sub-rede nas atualizações
Convergência lenta: Demora para se adaptar a mudanças

📌 RIPv2 (Versão 2)

Classless: Suporta VLSM/CIDR
Multicast: Usa endereço 224.0.0.9 para enviar atualizações
Com máscara: Inclui máscara de sub-rede nas atualizações
Mais eficiente: Suporta redes mais complexas

📌 RIPng (Next Generation)

Para IPv6: Adaptação do RIPv2 para IPv6
Mantém as mesmas características do RIPv2

⚖️ Vantagens e Desvantagens

✅ Vantagens

Simples de configurar
Amplamente compatível
Consome poucos recursos do roteador
Funciona bem em redes pequenas
Fácil de aprender e ensinar

❌ Desvantagens

Limitado a 15 saltos
Gera tráfego de rede constante (atualizações a cada 30s)
Convergência lenta
Não é escalável para redes grandes
Métrica simples (só conta saltos)

💡 Conclusão

O RIP é como uma bicicleta: perfeito para trajetos curtos e simples,
mas não é a melhor escolha para viagens longas e complexas!

🔧 Configurando RIPv1

📝 Passos para Configuração

Passo 1: Entre no modo de configuração do roteador
Passo 2: Ative o protocolo RIP
Passo 3: Adicione as redes diretamente conectadas

💻 Comandos Básicos

Router> enable
Router# configure terminal
Router(config)# router rip
Router(config-router)# network 10.10.10.0
Router(config-router)# network 192.168.1.0
Router(config-router)# end

⚠️ Importante

NO comando network, você NÃO precisa incluir a máscara de sub-rede
Informe apenas o endereço da rede classful (classe A, B ou C)
Por padrão, o RIP usa a versão 1

🎯 Exemplo Prático

Se seu roteador está conectado às redes 10.10.10.0 e 192.168.1.0,
você simplesmente adiciona essas duas redes com o comando network.
O RIP fará o resto automaticamente!

🔧 Configurando RIPv2

🆙 Melhorias do RIPv2

Suporte a sub-redes (VLSM/CIDR)
Inclui máscara de sub-rede nas atualizações
Usa multicast em vez de broadcast
Suporte a autenticação

💻 Comandos para RIPv2

Router> enable
Router# configure terminal
Router(config)# router rip
Router(config-router)# version 2
Router(config-router)# network 10.10.10.0
Router(config-router)# network 192.168.1.0
Router(config-router)# no auto-summary
Router(config-router)# end

🎯 Comando Importante

version 2: Ativa o RIPv2
no auto-summary: Desativa a sumarização automática de rotas

💡 Dica

O comando no auto-summary é essencial para redes modernas!
Ele permite que você trabalhe com sub-redes de tamanhos diferentes.

🔄 RIPv1 vs RIPv2

Característica RIPv1 RIPv2
Classificação Classful Classless
Máscara de Sub-rede ❌ Não envia ✅ Envia
VLSM/CIDR ❌ Não suporta ✅ Suporta
Tipo de Envio Broadcast (255.255.255.255) Multicast (224.0.0.9)
Autenticação ❌ Não suporta ✅ Suporta
Sumarização Sempre automática Pode ser desativada
Versão Padrão ✅ Sim Precisa ativar

🎯 Qual usar?

Sempre prefira RIPv2!
Ele é mais moderno, eficiente e compatível com redes atuais.

🔍 Verificando a Configuração

💻 Comando Principal

Router# show ip protocols

📊 O que esse comando mostra?

Qual protocolo de roteamento está ativo (RIP, OSPF, etc.)
Versão do RIP em uso (1 ou 2)
Redes anunciadas pelo protocolo
Temporizadores (30s para atualizações)
Se está recebendo atualizações dos vizinhos

📝 Outros Comandos Úteis

show ip route - Mostra a tabela de roteamento show ip route rip - Mostra apenas rotas aprendidas por RIP debug ip rip - Mostra atualizações RIP em tempo real no debug ip rip - Desativa o debug

⚠️ Cuidado

O comando debug gera muito texto no terminal
Use apenas para testes e sempre desative depois!

🎯 Resumo Final

RIP = Protocolo simples e automático para redes pequenas

✅ Use RIP quando:

Rede pequena (até 15 saltos)
Topologia simples
Facilidade de configuração é prioridade
Está aprendendo roteamento

❌ Evite RIP quando:

Rede grande e complexa
Necessita convergência rápida
Largura de banda é limitada
Precisa de métricas avançadas

📝 Comandos Essenciais

router rip ← Ativa o RIP version 2 ← Usa RIPv2 network 192.168.1.0 ← Adiciona rede no auto-summary ← Desativa sumarização show ip protocols ← Verifica configuração show ip route rip ← Vê rotas RIP

📚 Comparação com Roteamento Estático

Estático: Você configura cada rota manualmente
RIP: Os roteadores aprendem e compartilham rotas automaticamente

💡 Mensagem Final

O RIP é o ponto de partida perfeito para aprender roteamento dinâmico!
É simples, eficaz e funciona muito bem em ambientes pequenos.

Pratique no Packet Tracer e veja a "mágica" acontecer!
